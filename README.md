# Справочник пунктов выдачи Ozon для nutry-go.ru

Публичные данные о действующих пунктах выдачи и постаматах Ozon
(адрес, координаты, режим работы, срок хранения, рейтинг) — те же сведения,
что отображаются на карте ozon.ru. Обновляется ежедневно.

- `cities.json` — индекс городов (город → файл → число точек)
- `cN.json` — точки одного города
- `pvz-picker.js` — виджет выбора пункта для корзины сайта
